# Ala-Too Travel

Кыргызстандагы турлар тууралуу Айбарчын Икрамованын окуу долбоору.

## Мүмкүнчүлүктөр
- Кыргызча интерфейс, телефонго ылайык көрүнүш, күндүзгү/түнкү тема.
- Багыт, күндөрдүн саны жана бюджет боюнча тур издөө.
- Турдун программасы, дата жана адамдардын саны менен сынамык брондоо.
- Баа серверде эсептелет; туура эмес дата жана сан кабыл алынбайт.
- Админ: тур кошуу, баасын/сүрөтүн/программасын өзгөртүү, жашыруу; брондоону ырастоо, жокко чыгаруу же өчүрүү.
- Турлар жана брондоолор Cloudflare R2 сактагычында JSON объекттери болуп сакталат. Каталогдун параллель өзгөртүүлөрү текшерилет.

## Жандуу сайт
https://ala-too-travel-aibarchyn.slateounce1.chatgpt.site

Админ: сайттын `/admin` барагы. Сайт жеке; сайт ээсинин ChatGPT аккаунту керек.

## Текшерүү жана жыйноо
Node.js 22+ керек, кошумча npm пакеттери талап кылынбайт.

```sh
npm test
npm run build
```

`dist/server/index.js` — Cloudflare Worker. `BUCKET` R2 binding'и Sites аркылуу туташтырылат. `public/` файлдарын гана GitHub Pages'ке чыгаруу сервердик API менен админди иштетпейт.

## Кирүүнү коргоо
Бул версия **owner-private Sites** үчүн. Платформа ChatGPT аркылуу сайт ээсин киргизет; админ API ар бир операцияда платформанын `oai-authenticated-user-id` белгисин текшерет. Сайтты жалпыга ачуудан же башка көрүүчүлөрдү кошуудан мурун серверде сайт ээсинин ID'си боюнча роль текшерүүнү кошуу керек. Пароль же API ачкычы коддо сакталган эмес.

## Файлдар
- `public/index.html`, `style.css`, `app.js`: кардардын интерфейси.
- `public/admin.html`: админ интерфейси.
- `worker/api.js`: API, валидация, туруктуу сактоо.
- `scripts/build.mjs`: Worker жыйноо.
- `tests/api.test.mjs`: брондоо, баа, дата, уруксат жана сактоо текшерүүлөрү.

Бул окуу долбоору: чыныгы тур сатылбайт, төлөм алынбайт. Баалар менен маршруттар мисал үчүн. Сүрөттөр Unsplash'тан алынган иллюстрациялар, так жайгашкан жерди ырастабайт. Шрифт Google Fonts'тан жүктөлөт; жеткиликсиз болсо системалык шрифт колдонулат. Жеке маалыматтын ордуна сынамык маалыматты колдонуп, керексиз брондоолорду админден өчүрүңүз.

Сервердик тесттер өттү; бул чөйрөдө browser QA куралы болбогондуктан браузердеги көрүнүш жана кол менен кирүү агымы толук текшерилген эмес.
